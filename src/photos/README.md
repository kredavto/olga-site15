# Реальные фотографии

Положите сюда файлы — сборка сама подставит их вместо SVG-плейсхолдеров.

## Как это работает

1. Имя файла = ключ из таблицы ниже, расширение любое из `.avif`, `.webp`, `.jpg`, `.png`.
   Например: `hero-main.jpg`, `doc-orlova.webp`.
2. Для одного ключа можно положить несколько форматов — в разметку попадёт
   `<picture>` в порядке AVIF → WebP → растровый фолбэк.
3. Ключи без файла продолжают показывать сгенерированный SVG-плейсхолдер,
   поэтому фотографии можно добавлять по одной, а не все сразу.
4. Ширина и высота читаются из самого файла (PNG, JPEG, WebP), поэтому
   `width`/`height` в разметке всегда совпадают с картинкой и не дают скачка
   вёрстки. Для AVIF без растрового дубля берутся размеры из таблицы.

После добавления файлов запустите `npm run build` — в отчёте появится строка
«ФОТО N из 59 ключей заменены реальными снимками».

## Требования к снимкам

- Ширина не меньше указанной в колонке «Размер»; больше — можно.
- Формат: JPEG качества 80–85 или WebP; для первого экрана добавьте ещё AVIF.
- Изображения выводятся с `object-fit: cover` — держите главный объект ближе
  к центру кадра, края могут обрезаться.
- Проверьте права на публикацию: снимки людей и интерьеров требуют согласия,
  а фотографии со стоков — соблюдения их лицензии.
